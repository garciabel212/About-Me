# Flight v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Render a new six-stop Miami dusk flight composed for the light path landing, export it as HD, desktop and phone frame sets plus a per-frame occlusion matte, and have the landing draw the light path behind the buildings in every frame.

**Architecture:**
- **Film.** The film is rendered locally as before: Z-Image stills, then LTX-2.5 hops, then assembly. Assembly now targets exact stop frames.
- **Master and sets.** SeedVR2 upscales the film to a 1920×1056 HD master. Every frame set and every matte is cut from that master. SegFormer-B5 (ADE20K) runs on the master to make a soft "not sky, not water" matte.
- **Landing.** A new fixed canvas, `film__front`, redraws each painted frame cut to its own matte, between the light path and the text. It replaces the stop-only occluder images.

**Tech Stack:**
- Rendering and export: ComfyUI portable with its embedded Python 3 (`av`, `numpy`, `cv2`, `PIL`, `transformers` 5.17, `torch` 2.14+cu130), LTX-2.5, Z-Image-Turbo, SeedVR2 3B.
- Landing: React, TypeScript, GSAP ScrollTrigger, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-15-flight-v3-design.md`

## Review Focus

1. **Frame set changes mid-scroll** (resize across 768px or 1440px). Expected: the front layer clears and never draws a matte from the old set over a frame from the new set. Covered by Task 9, test `clears front on set change`.
2. **Fast scroll, where the painted frame is the `nearest` loaded one and not the playhead.** Expected: the front uses the matte of the painted index. Covered by Task 9, test `pairs matte by painted index`.
3. **Reduced motion or motion off.** Expected: each still is drawn with that stop's matte. Covered by Task 9, test `still mode draws stop matte`.
4. **Camera sway active.** Expected: `film__front` moves and scales with the film, so buildings never slide off the light. Covered by Task 9, change to `sway.test.ts`.
5. **Neighbouring mattes smoothed into a stop frame**, ghosting during a hold. Expected: stop frames use their own unsmoothed matte. Covered by Task 5, test `test_stops_unsmoothed`.

**Files:**
- Create: `tools/flight/zones.py`, `tools/flight/retime.py`, `tools/flight/matte_core.py`

**Interfaces:**
- Produces:
  - `zones.ZONES: dict[str, tuple[float, float, float, float]]`: (x0, y0, x1, y1) as fractions, keys `river brickell downtown bay beach sunset`.
  - `zones.zone_px(stop_id, w, h) -> tuple[int, int, int, int]`
  - `zones.zone_coverage(matte: np.ndarray[uint8 HxW], stop_id) -> float`: share of the zone with matte > 128.
  - `zones.sky_level(frame_rgb, matte) -> float`: mean luma of the top 15% of rows where matte < 128.
  - `zones.check_light_forward(levels: list[float], slack=2.0) -> bool`: each level ≤ the previous + slack.
  - `retime.MASTER_STOPS = [80, 228, 378, 528, 676, 824]`, `retime.MASTER_FRAMES = 825`.
  - `retime.retime(seg: list[np.ndarray], n: int) -> list[np.ndarray]`: exactly `n` frames; first and last are the input's first and last.
  - `matte_core.from_probs(probs: np.ndarray[C,H,W float32], clear_ids: list[int]) -> np.ndarray[H,W float32 0..1]`
  - `matte_core.smooth(mattes: list[np.ndarray], stops: list[int]) -> list[np.ndarray]`: weights 0.25 / 0.5 / 0.25; ends and stop indices unchanged.
  - `matte_core.drop_specks(m, min_frac=0.001) -> np.ndarray`
  - `matte_core.feather(m, px=1) -> np.ndarray`
  - `matte_core.to_alpha8(m) -> np.ndarray[uint8]`
